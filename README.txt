HOJA DE VIDA - ACTIVIDAD UNIDAD 2 - DISEÑO WEB

Proyecto: Hoja de vida web de Miguel Alfonso Padilla Saenz.

REQUERIMIENTOS IMPLEMENTADOS
- Estructura semántica HTML5 con header, nav, main, section y footer.
- Formulario HTML5 con form, input, textarea, select y label.
- Campos de texto, correo, teléfono, selección, casillas de verificación y botones de radio.
- Validación HTML5 mediante required, minlength, maxlength y pattern.
- Validación visual con clases is-valid/is-invalid de Bootstrap.
- Bootstrap 5.3.3 mediante CDN para grid, navbar, botones y formulario responsive.
- CSS3 personalizado con colores, tipografía, tarjetas, estados de formulario y media queries.
- jQuery 3.7.1 para animaciones y contador de caracteres.
- JavaScript para validación y mensajes de éxito o error.
- Diseño adaptable a móviles, tabletas y escritorio.
